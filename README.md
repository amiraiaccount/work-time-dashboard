# سیستم حضور و غیاب — داشبورد وب

داشبورد وب برای ثبت و پیگیری ساعات کاری با پشتیبانی کامل از تقویم شمسی و MongoDB.

## پیش‌نیاز

- Node.js 18+
- MongoDB (لوکال یا Atlas)

## نصب و اجرا

```bash
cd work-time-dashboard
cp .env.example .env
# فایل .env را ویرایش کن و MONGODB_URI را تنظیم کن

npm install
npm run dev
```

مرورگر را باز کن: [http://localhost:3000](http://localhost:3000)

## ویژگی‌ها

- صفحه ماهانه جداگانه با جدول روزانه
- ثبت ورود/خروج چندمرحله‌ای + نوع حضور (حاضر / مرخصی / تعطیل / غایب)
- محاسبه خودکار ساعت استاندارد:
  - شنبه تا چهارشنبه: ۷:۳۰
  - پنج‌شنبه: ۶:۳۰
  - جمعه و تعطیلات: ۰
- خلاصه ماهانه (روزهای مورد انتظار، ساعت واقعی، اختلاف)
- تقویم شمسی رنگی
- مدیریت تعطیلات اضافه
- کاملاً ریسپانسیو (موبایل + دسکتاپ)
- RTL و فارسی

## ساختار

```
app/
  api/          → API Routes
  dashboard/    → داشبورد کلی
  month/        → صفحه هر ماه
  calendar/     → تقویم شمسی
  settings/     → تنظیمات و تعطیلات
components/     → کامپوننت‌های UI
lib/            → ابزار تاریخ و ساعت + اتصال MongoDB
models/         → مدل‌های Mongoose
types/          → تایپ‌های TypeScript
```

## نکات

- تاریخ شمسی به صورت رشته `1405/05/03` ذخیره می‌شود تا فیلتر ماهانه سریع باشد.
- ساعات به صورت عدد اعشاری ذخیره و هنگام نمایش به `ساعت:دقیقه` تبدیل می‌شوند.
- برای استفاده چندکاربره بعداً می‌توان Auth اضافه کرد.
